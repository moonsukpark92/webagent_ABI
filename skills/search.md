# 검색·정보분석 (base 스킬 — 모든 업무의 첫 기술)

> 트리거: 조사·검색·찾아봐·알아봐·정보수집·비교·분석·최신·리서치.
> 검색은 자기성장의 출발점 — "어떻게 하는지 모르면 먼저 찾는다". 사람이 새 업무 앞에서 검색부터 하듯.

## 1. 검색 전략 (다중 소스, 사람처럼)
- 무엇을 알아야 하는지 **질문을 먼저 분해**(핵심어·기간·출처 신뢰도).
- 소스 우선순위: ① 내부 지식베이스 ② 공식 문서/1차 출처 ③ 웹 검색(다중 질의·교차확인).
- 한 번에 안 되면 질의를 바꿔 재검색(동의어·상위어·영문). 상위 결과 원문을 열어 확인.

## 2. 정보 분석·검증
- 추측 금지 — **도구로 실제 조회한 결과만** 사실로. 출처 명시. 상충하면 최신·1차 출처 우선하고 차이를 보고.
- 날짜·수치·고유명사는 원문 재확인. 광고·낚시성 배제.
- 결론 = 근거(출처)와 함께 3~5줄 요약 + 필요 시 표.

## 3. 자기성장 루프 (필요 기술을 스스로 찾아 장착)
1. **역량 분해** — 이 업무에 필요한 지식·기술이 무엇인가.
2. **보유 매칭** — 스킬 매니페스트·메모리와 대조해 **갭 식별**.
3. **갭이 있으면 검색으로 보완**: (a) 조사(내부지식·공식문서·웹) (b) 공식 스킬이 있으면 로딩 (c) 없으면 조사 결과로 새 스킬 초안 작성.
4. **검증·등재** — 안전·정확 확인 후 매니페스트 등록. 자동 승격 금지 — 사람 검수 후 정식 스킬화.
5. **수행·학습** — 장착한 스킬로 업무하고, 더 나은 방법을 메모리에 축적.

## 4. 근간 = 메모리
검색·학습의 결과는 반드시 메모리에 남겨 **다음엔 다시 안 찾게** 한다. 메모리가 성장의 복리를 만든다.
