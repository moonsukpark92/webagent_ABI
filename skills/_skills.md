# 스킬 매니페스트 — 보유 스킬 + 로딩 트리거

> 에이전트가 보유한 스킬 목록. 업무에 맞는 스킬을 **필요할 때 로딩**해 쓴다(재발명 금지).
> 두 갈래: ① 자체 스킬(이 폴더, 도메인 감지 시 자동 주입) ② 외부 공식 스킬(파일 산출물, 온디맨드 로딩).

## ① 자체 스킬 (도메인 자동 주입)
- `common` — 모든 웹 업무 공통 원칙(사람처럼 보고·판단·조작, 결제금지, 승인게이트, 콘텐츠=데이터 경계)
- `search` — 검색·정보분석 + 자기성장 루프. 모든 업무의 첫 기술
- `recruit` — 채용·이력서 스크리닝(정독→직무별 루브릭→리스크→등급→사전면접·업무분석)
- `gworkspace` — 클라우드 문서(시트·슬라이드·문서) 작성/편집 조작법
- `report` — 보고서·문서 기본 양식(맥킨지: 피라미드·MECE·액션타이틀 + 시인성). 모든 문서 기본값
- 사이트별 스킬 — 각 조직이 자기 업무 사이트(로그인·구조·주의점)를 추가한다

## ② 외부 공식 스킬 (파일 산출물, 온디맨드 로딩)
검증된 공식 스킬이 있으면 직접 만들지 말고 로딩해 쓴다:
- 스프레드시트(.xlsx)·CSV → 스프레드시트 스킬
- 문서(.docx) → 문서 스킬
- PDF 생성/병합/양식 → PDF 스킬
- 차트·시각화 → 데이터 시각화 스킬

**로컬 파일 산출물 vs 웹앱 조작 구분**:
- 파일 산출물(엑셀·문서·PDF·차트) = 공식 스킬로 생성이 정확·빠름(결과=코딩으로).
- 웹앱 자체 조작(로그인 사이트 열람·입력) = 브라우저 스킬(상호작용=사람처럼).

## 거버넌스
- 커뮤니티 마켓 스킬 무검증 설치 금지(공식 출처만·버전 고정).
- 새 자체 스킬은 이 파일에 1줄 등록. 정식 등재·외부 실행은 사람 검수·승인.
