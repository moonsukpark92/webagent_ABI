# 클라우드 문서 작성 (base 스킬 — 시트·슬라이드·문서)

> 트리거: 스프레드시트·시트·슬라이드·프레젠테이션·문서 작성/기입/편집.
> 전제: 브라우저가 해당 클라우드 서비스에 로그인 상태. 데이터 생성·공유·삭제 전 [확인요청].

## 공통 원칙
- 특정 폴더 안에 만들려면 먼저 그 **폴더를 열고** 새로 만들기 → 문서 종류 선택(그 폴더에 생성됨).
- 제목 변경: 좌상단 제목을 클릭해 새 제목 입력 → Enter. 저장은 자동.
- 되돌리기 어려운 동작(공유 설정 변경·삭제·전송) 전 반드시 [확인요청]. 조회·입력은 진행.
- 대량 입력 후 스크린샷으로 실제 반영을 검증(빈칸·깨짐 확인) — 안 보고 완료 선언 금지.

## 스프레드시트
- **표 채우기(효율)**: 데이터를 TSV(탭 구분)로 만들어 A1 선택 후 붙여넣기(Ctrl+V) → 셀에 자동 분배. 이게 가장 빠르고 정확하다.
- 클립보드 접근이 안 되면: A1 클릭 → 한 행을 "셀값[Tab]셀값[Tab]…[Enter]" 로 연속 입력(Tab=우측, Enter=다음 행).
- 셀 하나씩 클릭·타이핑은 느리고 깨지기 쉽다 — 지양.
- 서식: 헤더 굵게, 1행 고정. 숫자는 숫자로 입력.

## 프레젠테이션
- 제목 슬라이드에 제목/부제 입력 → 슬라이드 추가(+) → 레이아웃 선택 → 플레이스홀더 클릭 후 입력.
- 표준: 표지 → 요약 → 본문(1슬라이드 1메시지) → 결론/다음 액션. 1슬라이드 1메시지.

## 문서
- 제목 스타일 지정 후 본문. 개요는 단락 스타일(제목1/2). 표·목록은 삽입 메뉴/툴바.

## 주의
- "제목 없음" 상태로 방치 금지 → 규정 파일명으로 개명. 로그인 안 돼 있으면 [사람개입]으로 로그인 요청.
